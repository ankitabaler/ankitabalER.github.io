Ankita's Personal Portfolio
A one-page personal portfolio website created for GitHub Pages.

Publish on GitHub Pages
Create a GitHub repository (for example, adithi-portfolio).
Upload index.html.
Open the repository's Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root).
Save and wait for GitHub Pages to publish the site.
Before publishing, replace YOUR_GITHUB_LINK and YOUR_CONTACT_LINK in index.html with your actual links.
No external libraries are required.
